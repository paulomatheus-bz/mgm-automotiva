# MGM Automotiva

Site de apresentação dos serviços da MGM Automotiva, com informações para quem deseja conhecer o trabalho e entrar em contato.

**Site:** https://mgm-automotiva.vercel.app

## Objetivo

Apresentar os serviços e encaminhar interessados aos canais oficiais da empresa. Orçamentos e contratação são tratados diretamente com a equipe.

## Repositório

A demonstração está publicada, mas seu código ainda não foi incluído aqui. Este espaço mantém o registro do projeto até que a aplicação seja organizada no GitHub; por isso, não há linguagens detectadas.

## Manutenção

# MGM Automotiva

Site de apresentação dos serviços da MGM Automotiva.

**Acessar:** https://mgm-automotiva.vercel.app

A página ajuda quem está procurando um serviço a conhecer a empresa e encontrar os canais de contato. Orçamentos e contratação são feitos diretamente com a equipe.

O site está publicado, mas os arquivos da aplicação ainda não foram organizados aqui. Serviços, contatos e imagens devem ser conferidos com a empresa antes de qualquer atualização.
